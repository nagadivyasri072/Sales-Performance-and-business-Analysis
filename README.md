# Sales-Performance-and-business-Analysis
Developed an interactive Power BI dashboard to analyze sales performance, revenue, profit, product quantities, and shipping costs. Includes regional sales breakdowns, category-wise revenue analysis, territory comparisons, KPI cards, and interactive filters to support data-driven business decisions.
# Sales Performance and Business Analysis | Power BI

## 📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze sales performance and business metrics across different product categories, sales territories, and regions. It helps users understand revenue, profit, quantity sold, and shipping costs through visual reports.

## 🖥️ Dashboard Preview
![Sales Performance Dashboard](Dashboard-Screenshot.png)

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Compare sales across different geographical regions.
- Understand revenue contribution by product category.
- Analyze product quantity across sales territories.
- Compare revenue and freight costs across regions.

## 🛠️ Tools and Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Interactive Slicers and Filters

## 📊 Key Performance Indicators (KPIs)
- Total Quantity
- Total Sales
- Total Profit
- Total Shipping Cost

## 📈 Dashboard Features
- Regional sales breakdown using a doughnut chart.
- Territory-wise quantity comparison.
- Revenue analysis by sales region.
- Category-wise revenue distribution.
- Revenue versus freight comparison.
- Interactive filters for product categories, sales territories, and regions.

## 📂 Project Files
- `Sales-Performance-Analysis.pbix` — Interactive Power BI report.
- `Dashboard-Screenshot.png` — Dashboard preview.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard using the available slicers and filters.

## 💡 Business Value
This dashboard helps users compare regional performance, identify major revenue-contributing product categories, and monitor important sales and cost metrics.
